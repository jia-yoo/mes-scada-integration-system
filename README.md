# 주요 기여 및 문제 해결

## 1. 대용량 PLC 수집 데이터 처리 및 조회 성능 개선

### 배경

14개 수집 포인트에서 30초마다 PLC 데이터가 적재되는 환경으로, 일 약 4만 건의 데이터가 누적됨.

데이터 증가에 따라 30일 조회 시 응답시간이 5분 이상 소요되는 문제가 발생

### 담당 역할

* 데이터 조회 기능 개발
* 데이터 관리 로직 개선
* 성능 분석 및 개선

### 구현 내용

* 데이터 적재 현황 분석
* 스케줄러 기반 데이터 아카이빙 구조 설계 및 구현
* 당일 수집 데이터를 파일로 변환 및 저장
* 저장 완료 데이터 DB 자동 정리
* 파일로 변환 저장 후 DB 대신 파일에서 조회하는 방식으로 전환

### 성과

* 30일 조회 응답시간 5분 이상 → 수초 이내 단축
* 조회 성능 약 98% 개선
* 대용량 데이터 장기 운영 환경 확보

---

## 2. SCADA-MES 실시간 데이터 연계 기능 개발

### 배경

SCADA가 메인 시스템으로 운영되고 있었으며 MES 관리자 프로그램에서 현장 상황을 실시간으로 확인할 수 있어야 했음.

그러나 SCADA 측에서 TCP/IP 통신 구현이 불가능하여 대체 연동 방식이 필요

### 담당 역할

* SCADA 연계 기능 개발
* DB Trigger 기반 연동 구조 설계 및 구현

### 구현 내용

* SCADA 연동 방식 검토 및 대안 도출
* DB Trigger 기반 이벤트 처리 구조 설계
* SCADA 데이터 변경 시 자동 연계 로직 실행
* 실시간 데이터 동기화 기능 구현

### 성과

* SCADA-MES 실시간 데이터 연계 구현
* 데이터 누락 0건 운영 달성
* TCP/IP 미지원 환경에서 안정적 연동 구조 확보

## 3. SCADA 데이터 접근 제약 개선

### 문제

SCADA 프로그램 특성상 복잡한 Join Query 사용이 어려워 설비 기준정보 및 설정값을 한 번에 조회할 수 없는 상황

### 담당 역할

* 데이터 제공 구조 설계
* View 기반 조회 기능 개발

### 구현 내용

* SCADA 요구 데이터 분석
* 필요한 데이터를 미리 결합한 View 설계 및 구현
* SCADA에서 단순 조회만으로 필요한 데이터 접근 가능하도록 개선

### 성과

* SCADA 데이터 접근성 개선
* 필요 데이터 일괄 조회 가능
* 운영 편의성 향상

## 4. 요구사항 정렬 및 협업 프로세스 개선

### 배경

프로젝트 참여자별로 공유받은 내용이 달라 요구사항 해석 차이가 반복적으로 발생

담당자 간 직접적인 소통이 부족하여 동일 기능에 대한 이해가 서로 다른 상황이 지속됨

### 담당 역할

* 정기 회의 체계 제안
* 요구사항 정리 및 변경사항 공유
* 이해관계자 의견 조율 지원

### 구현 내용

* 정기 회의를 제안하여 담당자 간 의사소통 창구 일원화
* 모듈 완료 시점마다 이해관계자 검토 및 피드백 반영
* 요구사항 및 변경사항 문서화
* 협의 내용 공유를 통한 정보 불일치 최소화

### 성과

* 요구사항 누락 및 해석 차이 감소
* 담당자 간 커뮤니케이션 효율 향상
* 일정 내 프로젝트 납기 완료 기여
